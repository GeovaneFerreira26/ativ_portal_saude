# 🏥 Atividade Portal da Saúde - [Senai]

Atividade Prática: Criação de Portal de Saúde (ReactJS) - Consiste em um projeto de site, voltado para área de saúde, com 6 páginas no mínimo.

- [CSS Modules / Styled Components / Tailwind ]

## 🚀 Como Executar o Projeto

1. Clone o repositório:
git repo clone [ativ_portal_saude]

2. Entre na pasta do projeto:
cd ativ_portal_saude

3. Instale as dependências:
npm install

4. Inicie o servidor de desenvolvimento:
npm run dev
